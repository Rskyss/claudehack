### 缺陷与回归证据

| 情形 | 修改前观察 | 修改后观察 |
| --- | --- | --- |
| 配置缺失或损坏 | 没有拒绝连接，返回源码备用凭据 | 拒绝新连接，异常不输出凭据 |
| 无效必要字段 | 空主机、越界端口或空凭据被接收 | 拒绝无效配置 |
| 竞速超时后成功连接迟到 | 模拟测试观察到无人接收且未关闭的 socket | 迟到连接被关闭，工作线程结束 |
| HTTP 转发发送失败 | 已取得的上游连接未关闭 | 异常路径关闭连接 |
| 客户端断开 | 已取得的上游连接未关闭 | 异常路径关闭连接 |
| 正常请求及热加载 | 作为保留行为验证 | 正常隧道、额外字节、热加载和有界重试均通过 |

9 个测试方法全部通过。无效字段测试包含多个子场景；“9 项”指测试方法数，不把子场景重复计成更多测试。竞速测试缩短等待并用可控 socket 替身复现，不是对正式代理进行故障注入。
